# Naty Peinados (frontend)

    npm install
    npm run dev
    npm run build

Todo el contenido se edita en `src/data/data.js` (WhatsApp, categorías, fotos/videos, packs, precios, sobre mí y opiniones).
Fotos y videos: copialos a `public/media` y agregalos a la lista `MEDIA`. Logo: en `public/` y `CONFIG.logo`.

Estructura: `src/components/<Seccion>/`, `src/pages/Home.jsx`, `src/utils/whatsapp.js`.
